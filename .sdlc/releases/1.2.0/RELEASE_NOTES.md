# Release 1.2.0

**Date:** 2026-11-11
**Previous:** v1.1.5

## Highlights

Each feed now chooses what happens outside business hours, and the API key can live in wp-config.php
and is never shown on the settings page. Feeds are checked when saved, which they never were before
on Gravity Forms 2.5 and later. Ships after broadcaster-web v2.5.0 (BRO-1831, BRO-1877), live on
11 Nov 2026.

## What's New

### Added
- An Outside business hours setting on each feed: reply with the same template (the default), a
  different template, or don't reply (BRO-1877, BRO-1878).
- The API key can be set with `BROADCASTER_API_KEY` in wp-config.php, kept out of the database (BRO-1468).
- A saved API key is no longer shown: the page says "Saved key ending" and its last four characters
  above an empty field (BRO-1468).

### Changed
- A reply template is checked with Broadcaster when the feed is saved; if Broadcaster can't be
  reached, the feed still saves.

### Removed
- Template placeholders (BRO-1831).

### Fixed
- A feed is now checked when saved: no recipient field, or a template Broadcaster can't send as a
  reply, is refused with the reason.

## Breaking Changes

None intended. Visible changes for existing feeds:
- An older feed with no recipient field, or with a template Broadcaster refuses, is refused when next
  saved. Until then it keeps working as it does now.
- Placeholder settings on older feeds are no longer sent.

## Migration Guide

None. Existing feeds are read into the new choice whenever they are loaded, not migrated: a business
hours template alone, or the same name in both slots, reads as "same"; two different names, or only an
outside business hours template, reads as "different".
